# Original Mudshark site assets

These files were copied from the live Mudshark Pizza & Pasta site at the client’s direction for the Rotary rebrand. They are stored locally so the Rotary preview does not depend on production-site hotlinks.

## Used in the Rotary preview

- `hero-pizza.jpg` — hero photograph and Pizza category
- `category-salad.jpg` — Salads category
- `category-pasta.jpg` — Pasta category
- `category-wings.jpg` — Appetizers category
- `category-sub.jpg` — Subs + Sandwiches category
- `category-beer.jpg` — Beer + Cocktails category
- `menu-background.jpg` — menu photo break
- `beer-banner.jpg` — beer and cocktail banner
- `icon-*.webp`, `icon-appetizers.svg` — original category icons
- `pizza-spinner.webp` — original About-section pizza graphic
- `accent.png` — original menu accent graphic, retained for future use

## Retained but not shown

- `mudshark-brewery-logo.webp` — retained because “Mudshark Brewery” may be a supplier identity, but it is not shown until that relationship is verified for Rotary.
